How to get a token
  1. SSH into the Agim host and run agim
  2. Pick Manage web access tokens
  3. Pick Generate a new token
  4. Paste the printed value above
⚠️ The raw token is shown only once on the terminal — save it in a password manager.
Power users: agim token create works one-shot.
